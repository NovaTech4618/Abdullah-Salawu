Malformed HTML: Problem and Fix Table

Problem Location in broken.html Fix in fixed.html Why it matters
Missing document language Opening html element Added lang="en" Helps screen readers and other tools identify the page language.
Missing title head Added a descriptive title element Gives the page a useful browser-tab title and helps navigation and search.
Missing viewport metadata head Added viewport meta element Helps the page use the device width on mobile screens.
Missing closing tags h1, p, li and other elements in body Closed each element explicitly Prevents unintended parsing and makes the document easier to maintain.
Incorrect heading hierarchy h1 followed by h3; later h4 Used h1 for the page title and h2 for section headings Creates a meaningful, navigable outline for readers and assistive technology.
Duplicate IDs Two elements use id="item" Removed unnecessary duplicate IDs IDs must be unique within a document for labels, scripts and fragment links to target reliably.
Meaningful image lacks alt text img element Added descriptive alt text and a figure caption Provides an equivalent description for people who cannot see the image.
Broken relative links tips/cooking.html and ingredients.html links Replaced with a real external recipe link Avoids sending users to missing pages.
Incorrect form-label association Name label has no for; email label points to a nonexistent id Added matching for/id pairs for both inputs Associates labels with controls, improving accessibility and click/tap targets.
Missing image resource in project jollof-rice.jpg referenced but not supplied Changed to an external image URL and supplied alt text Avoids a broken local image reference when the remote image is available.
